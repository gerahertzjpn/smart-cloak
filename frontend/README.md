# 画面（frontend）

HTML・CSS・JavaScript だけで作っています（ビルド不要）。サーバー（backend）がこのフォルダをそのまま配信します。

| ファイル          | 画面                                         |
|-------------------|----------------------------------------------|
| `index.html`      | メニュー、イベント登録                       |
| `checkin.html`    | お預かり（撮影・棚の割り当て・引換券）       |
| `checkout.html`   | お引き取り（引換券QR → タグ照合 → お渡し）   |
| `shelves.html`    | 棚の状況、写真で探す（タグ脱落時）           |
| `label.html`      | 荷物タグの印刷                               |
| `ticket.html`     | お客様用の引換券ページ（`/t/<token>`）       |
| `js/common.js`    | 全画面共通（API呼び出し、ヘッダー、表示用の関数） |
| `css/style.css`   | 全画面共通のデザイン（濃紺 × ゴールド）     |

- サーバーから取得するデータは `docs/api.md` を参照。
- ハンドスキャナーはキーボードと同じく「文字＋Enter」を入力するので、入力欄（`scan-input`）で受け取る。
- 動かし方はリポジトリの `README.md` の「自分のPCで動かす」を参照。
